## 3 精修方案（优先级）
1. **P0 去掉 E1 绿团 + E2 灰盒**：绿团换成成排修剪绿篱（复用已验收 r2/hedge_green_fence，按长轴 z 正确缩放）+ 法桐 / jacaranda 行道树；灰盒换石材门柱（复用立面石材 + 线脚 + 铜灯）。只改 exterior.js 程序化部分，先做 r3plan 式平面再摆。
2. **P0 立面打光（E4/E8）**：统一为“傍晚蓝调”时段：天空换黄昏 HDR，立面加 4–6 盏地埋洗墙灯（暖白、上照），塔尖加轮廓光；hero_facade 贴图提亮 + 加 AO / 法线强度。
3. **P1 远景城市（E3）**：程序块换 LOD 城市剪影：近排（50–150 m）用 CC0 低模民国 / 欧式街屋（屋顶 + 檐口 + 窗套），远排（>150 m）用 2.5D 天际线卡片（Blender 渲出的城市立面贴图）+ 雾。
4. **P1 岗亭（E5）**：报刊亭换真正的值守岗亭（Blender 精建：石基座 + 木 / 铁框玻璃 + 坡顶 + 铜门牌），与城墙岗哨风格统一。
5. **P2 地面（E6）**：中轴铺装加分缝贴花 + 磨损 + 雨后湿反射遮罩；井盖 / 排水箅按 10 m 间距成列。
6. **P2 绿篱 / 车棚可读性（E7）**：看人视角图再定。
