## 字体层级

## 版式
- 主菜单 / 加载 = 一本摊开的巨幅论著：左页铜版画「叙事管理局正立面」线稿（SVG，tools/ui_facade.py 生成，带透视构造线、比例圆、阴影排线），右页 = 扉页（LIBER PRIMVS → 巨大「叙事管理局」金箔 → NARRATIVE BVREAV → 花饰 → 彩饰首字引文 → 双线进度尺 → 「进入」）。黄金比例版心，宽留白，订口阴影，页码 i / ii。
- 章节卡 = 扉页：象牙纸全屏，CAPITVLVM 罗马数字 + 彩饰首字（朱红底金框）+ 巨大标题 + 细金线自中线展开。
- 对话 = 页边批注：底部羊皮纸条，左侧朱红双竖线 + 说话人朱红小型大写（rubric），首字朱红。
- 文档 = 真实手稿纸页：纸纹、毛边阴影、内金双线框、页眉、首字下沉、页码花饰、朱印；翻页做 3D 书页翻入。
- 暂停 = 目录页 INDEX：游戏画面虚化 + 暖象牙罩，左侧竖排巨字「目錄」，右侧条目带点线前导，悬停金线滑入。
- HUD：目标 = 小羊皮纸签；交互提示 = 象牙签 + 圆章键位；准星 = 罗盘式细圈；区域标题 = 金箔大字 + 花饰。

## 动效清单（纯 CSS，transform/opacity/stroke-dashoffset，60fps）
1. 铜版画逐笔描绘：stroke-dashoffset 1→0，按层错峰（构造线 → 轮廓 → 柱 → 排线），总 ≤2.8 s。
2. 金箔微光：标题 background-clip:text，高光带 6 s 循环扫过。
3. 扉页错峰入场：页眉 / 标题 / 副标 / 花饰 / 引文各延迟 120–200 ms，cubic-bezier(.2,.7,.1,1)。
4. 章节卡：金线 scaleX 0→1、标题字距收拢、首字金框描边，入场 1.8 s；退场淡出 1.2 s。
5. 书页翻入：rotateY(-28°) + 左缘阴影渐消 0.7 s。
6. 进入游戏：书页向左翻起（rotateY -100°）+ 淡出 1.2 s。
7. 暂停条目悬停：金线从左滑入 + 点线前导变金。
8. 自然光：纸面一层暖光斑 12 s 缓慢漂移。
