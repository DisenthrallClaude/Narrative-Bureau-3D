## 动效清单（纯 CSS，transform/opacity/stroke-dashoffset，60fps）
1. 铜版画逐笔描绘：stroke-dashoffset 1→0，按层错峰（构造线 → 轮廓 → 柱 → 排线），总 ≤2.8 s。
2. 金箔微光：标题 background-clip:text，高光带 6 s 循环扫过。
3. 扉页错峰入场：页眉 / 标题 / 副标 / 花饰 / 引文各延迟 120–200 ms，cubic-bezier(.2,.7,.1,1)。
4. 章节卡：金线 scaleX 0→1、标题字距收拢、首字金框描边，入场 1.8 s；退场淡出 1.2 s。
5. 书页翻入：rotateY(-28°) + 左缘阴影渐消 0.7 s。
6. 进入游戏：书页向左翻起（rotateY -100°）+ 淡出 1.2 s。
7. 暂停条目悬停：金线从左滑入 + 点线前导变金。
8. 自然光：纸面一层暖光斑 12 s 缓慢漂移。
